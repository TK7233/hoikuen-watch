# 稲沢市 保育園空き状況 監視ツール

稲沢市の「認可保育園等の空き状況」ページの最新PDFが更新されたら、
Gmailにメールで通知します。日本時間 07:00〜20:00 は10分おきにチェックします。

## セットアップ手順

### 1. Gmailアプリパスワードを発行する
1. 通知を送りたいGmailアカウントで2段階認証を有効にする
   （Googleアカウント → セキュリティ → 2段階認証プロセス）
2. https://myaccount.google.com/apppasswords にアクセスし、
   アプリパスワードを新規発行する（名前は何でもOK、例: "hoikuen-watch"）
3. 表示された16桁のパスワードをメモしておく（後で使います）

### 2. GitHubリポジトリを作成する
1. GitHubで新規リポジトリを作成（Public推奨。Publicなら
   Actionsの実行時間が無料枠を気にせず使えます。内容はこのページの
   更新有無だけなので、公開しても問題ありません）
2. このフォルダ一式（.github, scripts, state, README.md）をそのまま
   リポジトリにアップロード（GitHub Desktopでも、Webのドラッグ&ドロップでもOK）

### 3. シークレットを登録する
リポジトリの Settings → Secrets and variables → Actions → New repository secret
から、以下を登録します。

| Name | 値 |
|---|---|
| `GMAIL_ADDRESS` | 送信元Gmailアドレス（例: your.name@gmail.com） |
| `GMAIL_APP_PASSWORD` | 手順1で発行した16桁のアプリパスワード |
| `NOTIFY_TO` | 通知を受け取りたいメールアドレス（送信元と同じでもOK） |

### 4. 動作確認
1. リポジトリの「Actions」タブ → 「保育園空き状況チェック」ワークフロー
   → 「Run workflow」で手動実行してみる
2. ログで「更新はありません。」と出れば正常。エラーが出た場合は
   シークレットの値を確認してください
3. 一度、`state/last_pdf.txt` の中身をわざと古いURLに書き換えてから
   手動実行すると、実際にメールが届くかテストできます

### 5. あとは自動で動きます
- 日本時間 07:00〜20:00 は10分おき、それ以外は21:00に1回チェックします
- PDFのリンクが変わったタイミングで自動的にメールが届きます
- 頻度を変えたい場合は `.github/workflows/check.yml` の `cron` を編集してください
  （cronはUTC基準です）

## 仕組み
- ページ内で最初に出てくる「〜aki.pdf」へのリンクを「最新のPDF」とみなします
  （過去分は下の「過去の空き状況について」に並ぶ仕様を利用）
- 前回チェック時に保存したURL（`state/last_pdf.txt`）と比較し、
  変わっていればメール送信 → ファイルを更新してコミット
